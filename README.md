A clean and lightweight Quran project designed for easy access, reading, and navigation.

## Overview

This project provides a simple way to explore the Quran in a structured and user-friendly format. It is designed for fast loading, easy reading, and straightforward integration into web or static interfaces.

## Features

- Clean and minimal interface
- Easy Quran navigation
- Responsive layout
- Lightweight and fast
- Simple project structure
- Easily customizable
